# 数据与权限边界

- 程序只面向配置好的一个联系人；模型输出不能指定收件人、路径或电脑命令。
- API Key 使用 Windows 凭据管理器，各模型配置独立命名。页面只返回是否已保存；显隐开关仅改变当前输入框的显示。
- 数据库、聊天导出、媒体、STYLE.md、真实回复样本、peer.json、local-runtime.json、访问日志和截图均为私有资料，不提交到仓库。
- 服务绑定 127.0.0.1，实施 Host/Origin/CSRF 校验。不要自行改成公网监听；这不是多用户云服务。
- 聊天、图片、引用和模型回复均不可信，网页用文本转义显示，模型内容不作为代码执行。
- 发送前核对上下文，发送后回读消息；点击前拦截的表情可以跳过，点击后的不确定结果必须暂停。
- 暂停可阻止后续发送，但已经提交的模型请求可能继续计费；token 记录保留真实已上报用量。
- Git 仓库只包含通用源码及有许可证的上游快照。私有仓库也不应存入凭据或聊天历史。
